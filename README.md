# student-management-system-java
A Student Management System built using Core Java 21, featuring CRUD operations, student search, marks validation, topper and average calculations, and 34 automated test cases.

# Student Management System

A Java-based Student Management System built using Core Java.

## Features

- Add Student
- View All Students
- Search Student by ID, Name, Course and Marks
- Update Student Details
- Delete Student
- Find Topper
- Calculate Average Marks
- Duplicate ID Validation
- Marks Validation

## Technologies

- Java 21
- OOP
- Collections Framework
- ArrayList
- Lambda Expressions
- Stream API

## Testing

A separate TestRunner class tests the StudentService functionality.

- Total Test Cases: 34
- Passed: 34
- Failed: 0

## Project Status

Core Java service implementation completed.
